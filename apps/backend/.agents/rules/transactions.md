# Транзакции

**Одна транзакция на запрос. Коммит делает зависимость, а не бизнес-код.**

- ручке, которая пишет, нужен `Uow`; ручке, которая читает, — `RoSession`;
- модуль объявляет свои псевдонимы сам, и пишущий обязан быть объявлен как
  `Annotated[AsyncSession, Depends(get_uow, scope="function")]`. Область
  `function` — это и есть инвариант «коммит → ответ» (раздел ниже), с областью
  по умолчанию клиент получит 2xx на несохранённые данные;
- `session.commit()` в модуле запрещён. Модуль вправе держать границу сам через
  `async with session.begin()` — но только когда операция сочетает базу с
  внешним I/O, как в `storage`;
- `expire_on_commit=False` у фабрики сессий обязателен: иначе сериализация
  ответа после коммита уходит в ленивую подгрузку и падает `MissingGreenlet`;
- **внутри открытой транзакции нет внешнего I/O**: ни S3, ни HTTP, ни
  публикации в брокер, ни `kiq()`. Порядок всегда один: короткая читающая
  сессия → закрыли → внешний вызов → короткая пишущая транзакция.

Единственное намеренное исключение — релей outbox
(`kernel/events/outbox.py`): он публикует сообщение, держа строчную блокировку
`FOR UPDATE SKIP LOCKED`, потому что отпустить её раньше значит опубликовать
сообщение дважды. Исключение описано в докстринге модуля; повторять его в
бизнес-коде нельзя.

**Проверяют:** `tests/test_architecture.py::test_modules_never_commit_the_session`
(коммит), `::test_uow_dependencies_close_before_the_response`
(область зависимости в любом модуле), `tests/test_deps.py`,
`tests/test_session.py`, `tests/test_commit_before_response.py` (граница
транзакции на настоящем uvicorn), `tests/test_storage.py::test_s3_calls_never_happen_inside_a_transaction`
(внешний I/O вне транзакции — в модуле `storage`).

Запрет внешнего I/O в транзакции для **нового** модуля автоматически не
проверяется: сторож из `test_storage.py` знает про `ObjectStorage`, а какой
клиент заведёт следующий модуль, заранее неизвестно. Скилл создания модуля
требует скопировать этот сторож в тесты модуля, если модуль ходит наружу; до
тех пор правило **проверяется ревью**.

При изменении Uow/dependency lifecycle или тестов commit-before-response читай
[границу коммита и проверку на uvicorn](references/commit-before-response.md).
