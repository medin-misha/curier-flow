# Проверка инфраструктуры

Рабочий каталог — `infra/`.

1. Просмотри `git diff -- infra/` и убедись, что изменение не удаляет данные
   без прямого запроса пользователя.
2. Выполни `make check`: оба Compose-файла должны пройти `config --quiet`.
3. Сверь новые переменные между `.env.example`, compose и кодом владельца.
4. Проверь порядок зависимостей и healthcheck; API liveness использует
   `/health/live`.
5. Если менялся Makefile, выполни `make help` и проверь описание новой цели.

Не выполняй `delete*` ради проверки.
