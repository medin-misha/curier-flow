# Пагинация

Только keyset по `(created_at DESC, id DESC)`. `OFFSET` не используется нигде.

- список отдаётся как `Page[T]` с непрозрачным `next_cursor`;
- у таблицы, которую листают, **обязан быть составной индекс**
  `Index("ix_<table>_keyset", Model.created_at.desc(), Model.id.desc())`,
  объявленный после класса: внутри тела класса колонок ещё нет и направление
  сортировки строкой не задать. Без индекса keyset вырождается в сортировку
  всей таблицы;
- `id` входит в ключ обязательно: `created_at` не уникален, и без второго
  компонента строки теряются на границе страниц.

**Проверяют:** `tests/test_pagination.py`, `tests/test_list_page.py`
(в том числе поведение при одинаковых `created_at` и отказ на модели без
нужных колонок).

Наличие keyset-индекса у новой таблицы **проверяется ревью**: «эту таблицу
листают» из схемы не выводится — `CRUD.list_page` вызывается в сервисе, а не
объявляется на модели. Требование продублировано в скиллах `new-module` и
`db-migration` и в `AGENTS.md` каждого модуля с пагинацией.
