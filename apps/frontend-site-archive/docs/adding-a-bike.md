# Сцена электро-транспорта

Лендинг содержит одну общую сцену транспорта для всех доступных вариантов. Не
создавай отдельные сцены или страницы для конкретных моделей: посетителю нужно
показать только наличие электро-транспорта и минимальную цену аренды.

## Медиа

Медиа сцены хранится в `public/transport/`:

```text
public/transport/
├── poster.png
└── loop.mp4
```

- `poster.png` обязателен и остаётся самостоятельным изображением при ошибке
  видео или запрете autoplay.
- `loop.mp4` используется как декоративное видео и загружается после первого
  показа сцены.
- Не импортируй файлы в TypeScript: Next.js раздаёт содержимое `public/` от
  корня сайта.
- Не заменяй текущие `<img>` и `<video>` на `next/image` без отдельной проверки
  качества пиксельной графики.

Если меняется медиа, обнови соответствие в [README каталога public](../public/README.md)
и проверь кадрирование на узком и широком экране.

## Контент

Локализованный текст общей сцены находится в `transportCopy` файла
`src/content/scenes.ts`. Для каждого языка должны быть заданы:

- `eyebrow` — короткая подпись сцены;
- `title` — общее предложение с минимальной стоимостью аренды без названия
  модели;
- `description` — описание доступного электро-транспорта.

Сохраняй одинаковую структуру для `ru`, `en` и `cs`. Порядок сцен и локализация
собираются функциями `composeScenes()` и `getScenes()`; не дублируй индексы в
компонентах.

## Проверки

После изменения контента или медиа выполни из `apps/frontend-site/`:

```bash
npm run typecheck
npm test
npm run build
```

Для видимых изменений дополнительно проверь `/`, `/en` и `/cs` на desktop и
mobile. Пролистай сцену транспорта, проверь постер, видео, число точек,
нумерацию, навигацию и отсутствие ошибок `404` в Console и Network.
