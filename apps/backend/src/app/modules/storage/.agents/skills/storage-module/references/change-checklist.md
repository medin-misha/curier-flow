## Если правишь модуль

- Новый лимит → поле в `StorageSettings`, переменная в `.env.example`,
  проверка в `_check_declared` (по заявке) и в `_mismatch` (по факту).
- Новая ручка, которой нужно хранилище, — тот же порядок: чтение, закрытие
  сессии, S3, пишущая транзакция. Тест-сторож не даст сделать иначе.
- Не добавляй `kiq()` в HTTP-ручки: работа, которую нельзя потерять, ставится
  через статус в таблице, а не через брокер внутри транзакции.
- `owner_id` не должен появиться в схеме запроса: он приходит из `actor_id` и
  передаётся только через `**overrides` в `CRUD.create`.
