# Модуль `health`

Три ручки о состоянии самого сервиса. Бизнес-данных модуль не трогает.

| Ручка            | Что отвечает                                              | Кто спрашивает            |
| ---------------- | --------------------------------------------------------- | ------------------------- |
| `GET /health/live`  | процесс жив, event loop крутится                         | docker/kubernetes liveness |
| `GET /health/ready` | база, брокер и объектное хранилище отвечают              | балансировщик, readiness   |
| `GET /health/info`  | имя, версия, окружение, ревизия схемы БД                 | человек и выкатка          |
