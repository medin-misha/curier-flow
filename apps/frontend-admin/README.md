# MFS Frontend Admin

Vue 3-панель для работы с реестром курьеров May Fleet Solutions. Интерфейс
перенесён из проекта OpenDesign и пока работает на локальных демонстрационных
данных: API будет подключено отдельным этапом.

## Локальный запуск

```bash
cd apps/frontend-admin
npm install
npm run dev
```

Vite откроет приложение по адресу `http://127.0.0.1:5173`.

## Проверка

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

Команда `npm run preview` запускает собранную версию по адресу
`http://127.0.0.1:4173`.

## Текущие возможности

- поиск, фильтрация и пагинация реестра;
- адаптивное представление таблицы;
- просмотр профиля, платформ и документов курьера;
- создание курьера с валидацией и локальным предпросмотром первого документа;
- управление модальными окнами с клавиатуры.

Демонстрационные данные находятся в `src/data/couriers.ts`. При подключении API
их можно заменить слоем запросов, не меняя структуру компонентов и типы домена.
