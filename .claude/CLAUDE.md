# О проекте
Это сервис-crm для флотилий доставок в Чехии задача которых быть посредником между курьером и сервисами типа Bolt\Foodora\Wolt.

Задачи:
1. Собирать заявки на лидов;
2. Генерировать договоры для курьером;
3. Хранить данные об автопарке флотилии;
4. Хранить расходы флотилии;

## Навигация и запуск
Проект состоит из:
- apps/ - тут лежит весь код и все сервисы.
- infra/ - тут лежит вся инфраструктура. От сюда же происходит запуск и управления

### Сервисы
- apps/backend - бекенд всего приложения

Если требуеться узнать список команд используй `make help` в infra/.

## Правила
1. При добавлении нового функционала делай коммит используя скилл `git-commit`
2. Запуск происходит из infra/
