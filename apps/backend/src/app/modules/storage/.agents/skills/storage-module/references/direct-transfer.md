## Файлы через backend не проксируются

Ни `UploadFile`, ни `StreamingResponse`, ни «маленький файл можно и через нас».
Проксирование стоит воркера uvicorn на всё время передачи: сотня параллельных
загрузок по минуте — это сотня занятых воркеров и очередь из отвалившихся по
таймауту обратного прокси запросов. Плюс лимит `client_max_body_size` у прокси,
плюс память процесса под тело. Хранилище умеет то же самое, стоит дешевле и
масштабируется без нас.

Практический вывод: `fastapi.responses.FileResponse` в этом модуле не нужен
вовсе. Схема ответа с таким же именем — это метаданные, а не содержимое.
