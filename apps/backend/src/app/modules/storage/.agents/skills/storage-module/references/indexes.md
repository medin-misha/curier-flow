## Индексы

- `ix_files_keyset` — `(created_at DESC, id DESC)`, без него keyset-пагинация
  вырождается в сортировку таблицы;
- `ix_files_status_created_at` — выборка обеих задач;
- `uq_files_bucket_key` — две строки на один объект означают потерянный объект:
  уборка одной удалила бы объект из-под второй.

Индекса по `owner_id` нет: колонка заполнится, когда появится аутентификация, и
вместе с фильтром «мои файлы» понадобится `(owner_id, created_at DESC, id DESC)`.
Раньше он был бы мёртвым грузом.
